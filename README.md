# Jose Bustamante — Computer Science ePortfolio

[Visit the public portfolio](https://todolomeos.github.io/josebustamante-eportfoliofinal/).

This CS-499 ePortfolio presents my Professional Self-Assessment, two-part Code Review, original and enhanced Weight Tracker artifacts, and narratives for Software Design and Engineering, Algorithms and Data Structures, and Databases.

The portfolio includes the final Module Seven narratives and Professional Self-Assessment, with downloadable Word copies. Core application functionality was compiled and manually tested in the Android Emulator during the enhancement work. The published enhanced artifact also includes a later SQLite version 3 to version 4 migration. That migration was compiled and validated on Android 14/API 34 with three passing instrumentation tests covering migration, foreign keys, integrity, user-scoped CRUD operations, independent goals, and two-user data separation.

The original local project folder remains on DATABASE_VERSION 3; the published version 4 artifact was validated separately in an isolated test copy. The final Word documents are available from the portfolio home page and artifact page.
